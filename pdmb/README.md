# 괴이재난관리국 웹페이지

HTML/CSS/JS로 구성된 반응형 세계관 소개 페이지입니다.

## 실행
- `index.html`을 브라우저에서 열면 됩니다.
- 인터넷 연결 시 Google Fonts가 적용됩니다. 폰트 연결이 안 되면 시스템 기본 글꼴로 표시됩니다.

## GitHub Pages 배포
1. GitHub 저장소에 `index.html`, `style.css`, `script.js`를 업로드합니다.
2. 저장소의 Settings → Pages로 이동합니다.
3. Build and deployment에서 Deploy from a branch를 선택합니다.
4. 브랜치와 `/ (root)`를 선택하고 저장합니다.

## 수정 안내
- 메뉴/문서/인물 내용: `index.html`
- 색상/레이아웃/반응형: `style.css`
- 검색/필터/모바일 메뉴/시계: `script.js`

## 설정 관련 주의
현재 등급 구간과 부서 업무는 웹페이지 시안을 위해 요약·정리한 초안입니다. 확정된 세계관 설정에 맞춰 문구를 수정해 주세요.
