# 괴이재난관리국 웹페이지 개편본

HTML/CSS/JS 기반의 반응형 세계관 아카이브입니다. 업로드된 `info.txt`의 설정을 기준으로 조직·직위·등급·인물·괴이 기록을 구성했습니다.

## 실행 및 배포
- `index.html`을 브라우저에서 열면 됩니다.
- GitHub Pages를 사용할 경우 저장소 루트에 `index.html`, `style.css`, `script.js`, `images/`를 업로드한 뒤 Settings → Pages에서 배포 브랜치와 `/ (root)`를 지정하세요.

## 인물 이미지 넣기
1. `images/characters/` 폴더에 인물 이미지를 넣습니다.
2. `script.js`의 `people` 배열에서 해당 인물의 마지막 값(이미지 파일명)을 실제 파일명으로 수정합니다.
3. 예: `haemujin.webp` → `images/characters/haemujin.webp`.
4. 세로형 프로필 이미지(WebP/PNG 권장)를 사용하세요. 이미지가 없으면 이름 첫 글자가 대체 표시됩니다.

## 수정 위치
- 문구와 레이아웃 구조: `index.html`
- 색상·글꼴·반응형 디자인: `style.css`
- 인물 데이터, 검색·필터, 시계: `script.js`

## 설정 적용 주의
- 특수방위별원은 제공 파일에 따라 관리국장 직속으로 배치했습니다.
- 직위와 등급은 제공된 표현을 유지했습니다. 등급별 접근 제한 등 파일에 없는 규정은 새로 만들지 않았습니다.
- 네임드 괴이의 상세 외형·능력은 제공 파일의 지침에 따라 싣지 않고 간단한 개요만 표시합니다.
- 인물의 주령기·권능 표기는 원문을 유지했으며, 개별 구분이 자료에서 명확하지 않은 경우 임의로 분리하지 않았습니다.


## 최근 개편 사항
- 조직 구성 요약을 제거하고 조직 구조만 남겼습니다.
- 관리국장 바로 아래 상위 영역에 감사위원회를 배치하고, 3개 단을 하위 조직으로 정리했습니다.
- 부서 설명은 가로 흐름으로 배치하고 모바일에서는 읽기 쉬운 형태로 줄바꿈합니다.
- 본부 건물 층별 구조를 제거했습니다.
- 초자연 개념은 괴이·협력영물·주령기·권능 네 가지 용어 설명만 제공합니다.
- 인물 기록 아래에 괴이 기록을 추가했으며 소재급·중재급·대재급·천재급·무상급 순서로 분류합니다.
